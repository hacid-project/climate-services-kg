# Requirements log

This folder records requirements for a **declarative dataflow system** for knowledge-graph construction. They come from practical work on this pipeline: problems met, workarounds adopted, and structural decisions.

- `log.md` is the log. One entry per requirement, ids `R-NNN`, never renumbered.
- Add an entry when you hit friction, write a workaround, or make a structural decision. Two or three lines are fine.
- Link evidence (commit, PR, issue, file). Mention the id in related commit messages (`Refs R-012`).
- Categories are fixed (see the top of `log.md`), so entries can be grouped later.

The log is research material for papers on declarative dataflow and on this KG's construction. It is not a backlog: entries do not need to be implemented here.
